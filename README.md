# 📝 Vocab Test · 英语单词复习网页

一个**零依赖、纯静态**的英语单词测验网页，托管在 GitHub Pages 上，手机和电脑打开即用。

> 🌐 在线地址：**https://hunggy.github.io/vocab-test/**
> 仓库地址：https://github.com/Hunggy/vocab-test

内置 **240 组词（480 个单词）**，按每周一批划分，每组都配有英文例句与中文翻译，主打「每周背一组、一两天速通」的突击式复习。

---

## ✨ 功能一览

### 四种题型
| 题型 | 说明 |
| --- | --- |
| 英文选中文 | 看单词选释义，配双语例句（例句会自动把同义词替换成目标词）|
| 中文选英文 | 看释义选单词，干扰项会自动排除同义词，避免「送分」|
| 句子填空 | 例句挖空成 `____`，选择应填入的单词 |
| 🔊 听音拼写 | 播放发音后手动拼写单词，大小写不敏感 |

### 复习机制
- **错题循环**：答错后按 **5 → 10 → 20 题**的间隔自动重现，直到答对为止
- **间隔复习**：答对的词会在 15 题后再出现一次巩固
- **📊 错题统计**：按错误次数倒序排列，一眼看出顽固词
- **⭐ 难词标记 / 🔪 斩词**：标记难词单独刷，或把已经烂熟的词斩掉不再出现
- **← 历史回顾**：随时回看上一题的正确答案，→ 回到当前题

### ⚡ 速通模式
把当前范围的单词打乱后连续刷完，自动跳下一题，结束后显示正确率，并可一键 **🎯 重练本次错题**，趁热打铁当场扫盲。

速通中途也能 **← 回看上一题**（没反应过来刚才是哪个词时很有用）：回看会暂停自动跳题，显示该词的完整信息、四个选项，并把正确答案标绿、你选错的标红；**←** 可以继续往前翻更早的题，**→** 逐条往回翻，回到最新一题即恢复原来的答题现场并继续速通。听音拼写模式下还会显示你当时输入的内容。

### 🃏 翻卡自测
在「模式」下拉框选择 **🃏 翻卡自测**，进入经典的自评卡片：**凭记忆而不是靠排除选项**。

- **正面**只有英文单词 + 英文例句（不显示任何中文），先自己回想释义
- 点击卡片 / 按空格**翻面**，背面给出中文释义、例句翻译，以及「`单词 = 同义词`」的对照
- 翻面后自己判断：**✓ 记住了**（出队）/ **✗ 还没记住**（记一次错题，**推迟 5 张后必定重现**，直到你认下它为止）
- 顶部实时显示「记住 N / 剩余 M / 未记住 X」，全部翻完后给结算，可一键 **🔁 再翻一遍未记住的**
- 点「✗ 还没记住」会累加到全局错题统计，之后用「只复习错题」模式还能接着刷
- 此模式下速通和题型切换会临时禁用（两者逻辑不兼容），⭐ 难词标记、🔪 斩词、🔊 发音照常可用

### 其他
- **范围筛选**：按日期批次（6 组）或「全部」，也可只刷前一半 / 后一半 / 错题 / 难词 / **🃏 翻卡自测**
- **📖 单词浏览**：卡片列表 + 实时搜索（支持英文或中文），同义词合并展示且各自带发音按钮；**速通模式下也能随时打开查词**，打开时会暂停自动跳题，点「返回速通」继续（Esc 同样可退出）
- **🔊 发音**：基于 Web Speech API 的朗读，支持「自动发音」开关（英文选中文模式下自动朗读，不泄露答案）
- **进度导出 / 导入**：JSON 备份学习进度，跨设备或换浏览器可恢复
- **CSV 导入词库**：随时导入自己的单词表（导入后选择「📥 自定义词汇」）
- 🌙 深色模式、A-/A+ 字号调节，所有偏好自动记忆

### 快捷键
| 按键 | 作用 | 按键 | 作用 |
| --- | --- | --- | --- |
| `1`~`4` | 选择答案 | `A` | 标记 / 取消难词 |
| `Enter` / `空格` | 下一题（听音拼写下为提交答案）| `S` | 斩词 |
| `←` | 回看上一题（速通中可连续往前翻）| `V` | 重新播放发音 |
| `→` | 返回当前题（速通中为逐条返回）| `Esc` | 退出速通 / 浏览模式、关闭弹窗 |

翻卡自测模式下：`空格` 翻面、`→` 记住了、`←` 还没记住（`V` 发音、`A` 难词、`S` 斩词不变）。

## 🚀 本地运行

因为页面用 `fetch` 加载词库，**不能直接双击 `index.html`**（`file://` 协议会被浏览器拦截）。请启动一个本地服务器：

```bash
# 任选一种
python -m http.server 8000
npx serve .
```

然后访问 http://localhost:8000 。


- `*.csv`：整理词库时的原始单词表素材
- `vocab_config.json`：桌面版的进度存档格式

## 📚 词库说明

`vocabulary.json` 的结构如下：

```json
{
  "groups": {
    "2026-05-09": [
      {
        "id": 81,
        "a": "evoke",
        "b": "elicit",
        "ch": "唤起",
        "ex": "The smell of fresh bread evokes happy memories of my grandmother's kitchen.",
        "cn": "新鮮麵包的香味喚起了我對祖母廚房的美好回憶。"
      }
    ]
  }
}
```

| 字段 | 含义 |
| --- | --- |
| `id` | 组内编号，**同义词对共享同一个 id**（浏览模式据此合并卡片）|
| `a` / `b` | 一组同义词/近义词，会被展开成两张独立单词卡 |
| `ch` | 中文释义 |
| `ex` / `cn` | 英文例句 / 中文翻译 |

现有批次：5/9、5/16、5/23、5/30、6/6、6/20，**每组 40 组同义词（80 张卡），编号 81–320，共 240 组 / 480 词**。

### 新增一批单词（每周更新时做这个就够了）

1. 在 `vocabulary.json` 的 `groups` 里加一个键，值为该批次的单词数组；
2. 在 `index.html` 的 `#dateSelect` 里加一个 `<option value="MMDD">显示文字</option>`；
3. 在 `script.js` 的 `getDateMapping()` 里补上 `'MMDD': 'YYYY-MM-DD'` 的映射。

> 第三步容易漏——如果不加，`script.js` 会把 `'MMDD'` 原样当作日期去匹配 `vocabulary.json` 里的键，导致选这一批时页面显示「没有可用单词」。

### 📥 不想改 JSON？用 CSV 导入

点工具栏的 **📥 CSV** 按钮导入自己的单词表，导入后把批次下拉框切到「📥 自定义词汇」即可开刷。

**CSV 必须有第一行表头**，字段名为（大小写不限，顺序随意）：

| 列名 | 是否必填 | 对应内容 |
| --- | --- | --- |
| `word` | ✅ 必填 | 英文单词 |
| `chinese` | ✅ 必填 | 中文释义 |
| `synonym` | 可选 | 同义词 / 近义词 |
| `example` | 可选 | 英文例句 |
| `example_cn` | 可选 | 例句中文翻译 |

少了 `word` 或 `chinese` 会直接提示「CSV 文件必须包含 word 和 chinese 列」。

```csv
word,chinese,synonym,example,example_cn
eloquent,雄辩的,articulate,"She gave an eloquent speech.","她发表了一场雄辩的演讲。"
meticulous,一丝不苟的,thorough,"He is meticulous about details.","他对细节一丝不苟。"
resilient,有韧性的,"The plant is resilient to drought.","这种植物耐旱。"
```

数据行支持逗号和引号：含有逗号的字段请用双引号包裹，例如 `"He is meticulous, always."`。

> ⚠️ **三个容易踩的坑**
> 1. **必须存成 UTF-8 编码**。Excel 在中文系统上另存 CSV 默认是 GBK，导入后会变乱码；请用「另存为 → CSV UTF-8」或用记事本转换编码。
> 2. **刷新页面后自定义词汇会消失**。CSV 导入的词只存在于当前页面会话的内存里（内部 id 为负数），不会被保存，也不会写回 `vocabulary.json`。想长期用请改 JSON 词库，或搭配 **📤 导出**进度一起备份。
> 3. **一行一张卡**。CSV 每个单词只生成一张卡片，`synonym` 只是当作同义词显示；这和 JSON 词库里 `a`/`b` 会展开成两张卡不同。

> 表头行本身请勿用引号包裹（如 `"word","chinese"`），解析器按逗号切分表头，带引号会导致列识别失败。

## 🌍 部署（GitHub Pages）

已配置 Pages，推送到 `main` 分支后会自动更新，通常一两分钟内生效：

```bash
git add .
git commit -m "feat: 新增 XXX 批次单词"
git push origin main
```

注意：Pages 渲染的是 `main` 分支。早期版本曾推到 `master` 分支导致页面不更新，本地分支现已统一为 `main`。

## 🔒 数据与隐私

所有学习进度（掌握情况、错题次数、难词、深色模式、字号等）保存在浏览器 `localStorage` 的 `vocab_test_progress` 键下，**不上传服务器、无后端、无第三方统计**。清除浏览器数据会丢失进度，建议定期用 **📤 导出**按钮备份成 JSON。

## 🛠 技术栈

原生 HTML + CSS + JavaScript，**无框架、无构建步骤、无第三方依赖**。发音使用浏览器内置的 Web Speech API（Chrome / Edge / Safari 支持较好，Firefox 视系统语音包而定）。
